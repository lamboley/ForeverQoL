# Security policy

## Supported versions

Security fixes and updates are only applied to the latest released version. So always try to be up to date.

## Reporting a vulnerability

**Please do not open a public issue for a security problem.**

Report it privately through GitHub, from [Security → Report a vulnerability](https://github.com/lamboley/foreverqol/security/advisories/new). That opens a private advisory visible only to you and the maintainer.
